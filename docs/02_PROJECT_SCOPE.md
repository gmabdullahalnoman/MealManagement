# Project Scope

## In Scope

The first version of the Meal Management System will include the following features:

### Authentication

- User Registration
- User Login
- Password Encryption
- Profile Management

---

### Meal Group Management

- Create Meal Group
- Join Meal Group via Invitation Link
- Secret Code Verification

---

### Role Management

- Admin
- Member
- Viewer

---

### Member Management

- Invite Members
- Manage Member Roles
- Activate / Deactivate Members

---

### Meal Management

- Individual Meal Entry
- Bulk Meal Entry
- Meal Request within Time Limit
- Guest Meal Support

---

### Market Management

- Market Entry
- Bulk Market Entry
- Expense History

---

### Asset Management

- Initial Asset Entry
- Additional Asset Entry
- Asset History

---

### Accounting

- Meal Rate Calculation
- Member Balance Calculation
- Carry Forward Balance
- Monthly Closing

---

### Reports

- Member Report
- Meal Report
- Market Report
- Monthly Summary

---

## Out of Scope

The following features are NOT included in Version 1:

- Mobile Application
- Online Payment Gateway
- SMS Integration
- Email Notifications
- Push Notifications
- Grocery Inventory Management
- Multi-Currency Support
- Multi-Organization Dashboard
- AI-based Analytics
- Offline Synchronization
