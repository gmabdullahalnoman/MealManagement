# Stakeholders

This document defines the stakeholders of the Meal Management System and their primary responsibilities.

---

# System Administrator

The System Administrator manages the platform.

Responsibilities:

- Monitor the system.
- Maintain the application.
- Manage the database.
- Fix production issues.
- Configure system settings.
- Support users when necessary.

---

# Group Admin

The Group Admin is responsible for managing a Meal Group.

Responsibilities:

- Create and manage the Meal Group.
- Invite new Members.
- Create Members directly.
- Manage Member roles.
- Promote or demote Group Admins.
- Manage Group settings.
- Start a new month.
- Perform Monthly Closing.
- Correct incorrect business entries.
- View all reports.

---

# Member

A Member participates in the daily activities of a Meal Group.

Responsibilities:

- Join a Meal Group.
- Manage personal profile.
- Submit Personal Meal Entry.
- Use Daily Meal Sheet.
- Create Bazar entries.
- View reports.
- Participate in monthly meal management.

---

# Viewer

A Viewer has read-only access.

Responsibilities:

- View Meals.
- View Bazar.
- View Reports.
- View Monthly Summary.

A Viewer cannot create, update or delete any business data.
