### Project Name
>Meal Management System

### Problem Statement

>Currently, meal management is handled using Excel. 
Managing member meals, deposits, expenses, bazar costs, and monthly calculations manually can become time-consuming and error-prone.
The system will provide a centralized application to manage these activities and automate important calculations.

### Project Objective
*Build a small, reliable meal management system that:*

- Replaces the core Excel-based workflow.
- Automatically calculates meal and financial information.
- Keeps member, meal, deposit, expense, and bazar records organized.
- Provides useful monthly summaries and reports.
- Demonstrates real-world Java, Spring Boot, and PostgreSQL development.
### Target Users
- Meal Group Admin — manages members, meals, financial records, and bazar information.
- Meal Group Members — view their own meal and financial information.

### Core Modules
```
   Member Management 
   Meal Management
   Deposit & Expense Management
   Bazar Management
   Monthly Calculation
   Basic Reports
```

### Initial Scope
*The first version will focus on the core monthly meal-management workflow:*

- Manage active members.
- Record daily meals.
- Record member deposits/expenses.
- Maintain total asset separately from total bazar.
- Record bazar expenses.
- Calculate monthly meal information.
- Calculate member-wise financial balances.
- Provide basic monthly summaries.
- Expose the functionality through REST APIs.

***Future features such as authentication, advanced reports, notifications, frontend UI, and additional financial features may be considered after the core system is stable.***
