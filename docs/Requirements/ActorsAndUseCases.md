- Meal Group Member
- System — for automated calculations/processes
### Admin Use Cases
- Manage members
- Manage meals
- Manage deposits/expenses
- Manage bazar records
- View monthly calculations
- View reports

- View own deposit/expense records
- Add/update own deposit records
- View/add/update own bazar records
### System Use Cases
- Calculate total meals
- Calculate total asset
- Calculate total bazar
- Calculate meal rate
- Calculate member-wise balance
- Generate monthly summaries
