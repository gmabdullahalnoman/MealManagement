### Member Management
- FR-001: The system shall allow the Admin to add a member.
- FR-002: The system shall allow the Admin to update member information.
- FR-003: The system shall allow the Admin to activate/deactivate a member.
- FR-004: The system shall allow users to view permitted member information.
### Meal Management
- FR-005: The system shall allow members to add their meal records.
- FR-006: The system shall allow members to update their permitted meal records.
- FR-007: The system shall allow the Admin to manage meal records.
- FR-008: The system shall provide period-wise meal totals.
### Deposit & Expense Management
- FR-009: The system shall allow members to add their deposit/expense records.
- FR-010: The system shall allow members to update their permitted records.
- FR-011: The system shall allow the Admin to manage financial records.
- FR-012: The system shall calculate Total Asset from member financial records. 
### Bazar Management
- FR-013: The system shall allow members to add bazar records.
- FR-014: The system shall allow permitted users to update bazar records.
- FR-015: The system shall allow the Admin to manage bazar records.
- FR-016: The system shall calculate Total Bazar from bazar records.
### Monthly Calculation & Reports
- FR-017: The system shall calculate total meals for a selected period.
- FR-018: The system shall calculate the applicable meal rate.
- FR-019: The system shall calculate member-wise financial balances.
- FR-020: The system shall provide a monthly summary.
- FR-021: The system shall provide basic member-wise and financial reports.
### Future Enhancement
- FR-022: The system should support role-based access control for different user permissions.
